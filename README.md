# 🚀 Central de Projetos

Bem-vindo ao seu Workspace Oficial de Desenvolvimento! 
Este ambiente foi pré-configurado e estruturado pelo seu Assistente de IA para manter todos os seus códigos organizados desde o primeiro dia.

## 📂 Estrutura de Pastas

Para manter tudo padronizado, os projetos devem ser separados nas seguintes categorias:

*   🌐 **`Web/`** -> Projetos Front-end e Full-stack (React, Next.js, Vue, HTML/CSS). Tudo o que rodar no navegador vai aqui.
*   📱 **`Mobile/`** -> Aplicativos para celular (React Native, Flutter, Android Nativo).
*   ⚙️ **`Backend/`** -> Motores, APIs e Microsserviços (Node.js, Python, APIs RESTful, integrações de Banco de Dados).
*   🤖 **`Scripts/`** -> Códigos rápidos de automação, web scraping, inteligência artificial e análise de dados (principalmente Python).
*   🧪 **`Playground/`** -> Sua área de testes. Vai testar uma biblioteca nova ou fazer um rascunho de código? Jogue aqui sem medo de sujar os projetos reais.

## 🔧 Ferramentas Básicas do Sistema
*   **Git:** Habilitado para controle de versão.
*   **Node.js & npm:** Habilitado para ecossistema JavaScript.
*   **Python:** Habilitado para automações e IA.
*   **Docker:** Motor de infraestrutura e bancos de dados (Instalação manual requerida pelo usuário).
*   **DBeaver:** Cliente oficial para gerenciar os Bancos de Dados.
